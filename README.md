# SAM – Smoke Alarm Maintenance

One-page web app (index.html + app.js) on Supabase, hosted on GitHub Pages.

- `config.js` – Supabase URL + publishable key, Framer website link
- `supabase/01_sam_setup.sql` – tables, security rules, quiz marking (already run)
- `supabase/02_sam_content.sql` – course modules, questions, guides, FAQ copied from Airtable
